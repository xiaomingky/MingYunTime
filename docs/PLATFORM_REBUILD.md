# 四平台独立接入进度

范围：依据 `反编译/api-analysis/全部API清单.md` 及对应源码，逐平台接入有效音乐业务操作。排除广告、埋点、崩溃上报、推送 SDK 和单纯资源地址。顺序：汽水、QQ、网易云、酷狗。保留已有功能，第三方音乐业务后端在替代实现通过测试后移除；官方安全组件单独记录。

## 验收规则

- 静态声明、独立实现、模拟验证、游客实测、真人账号验证分别记录。
- HTTP 200、空数组、占位按钮、试听均不能证明完整功能已验收。
- 未获得真实账号权限的写入不在自动测试中向平台执行；测试请求构造、权限拒绝、错误传播、账号切换与状态更新。
- 每个平台完成功能映射、界面连接、账号隔离与回归测试后，再进入整体替换阶段。
