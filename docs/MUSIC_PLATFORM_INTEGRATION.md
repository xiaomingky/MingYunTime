## QQ 独立接入

- `electron/qq-client.js` 自行组织官方公开 HTTPS/RPC 请求，已连接操作不经 localhost 或其他音乐 API 项目的业务模块。未替换通道仍使用旧服务，依赖暂未删除。
- 单曲/专辑搜索采用真实公开搜索合约；歌手/歌单/MV 使用官方 Lite 匿名会话。标准无签名搜索可能返回 `code=0,is_filter=-2` 与空列表，这种结果视为平台拒绝，不能当成搜索为空。
- 曲目详情读取实际 `file.media_mid`，据此申请所选音质播放授权；不将空 purl 拼成可播放地址。实际音频时长与整曲信息比较，短片段按试听显示，不绕过账号/会员权限。
- 歌词按准确歌曲 ID 获取，保留项目原有逐字歌词请求；标准歌词失败时仍可保留有效逐字结果。歌词网络请求设有超时。
- 专辑、歌单、榜单、歌手歌曲/专辑均接入继续加载。榜单使用官方返回期次；歌手目录适配上游固定 80 项分页，避免每翻一页重复或丢数据。
- 用户歌单使用官方 Web `GetPlaylistByUin`，从目录定位“我喜欢”再读取完整曲目。APK 的 `CgiGetPlaylistByUin` 对明文 UIN 返回拒绝，没有把 Web 等价业务计为 APK 原方法验收。
- 登录打开官网并触发其真实登录弹层，QQ 与微信二维码均已实际解码；窗口隔离、重复打开和取消通过。Cookie 必须经账号鉴权接口验证后才接受，公开昵称或公开歌单不能作为登录证据。
- Cookie 在主进程使用 safeStorage 加密保存；renderer 仅保留内存会话，旧 localStorage Cookie 验证成功后迁移。重启重新鉴权；退出及迟到登录响应不会重建已清理会话。原有 Cookie 查看/复制保留。
- 数字专辑展示真实目录；票务旧服务目前仅返回过期记录，过滤后为空，不把 2023 年演出显示成当前演出。相似歌手旧接口实测 HTTP 500，仍待替代；账号收藏与歌单写入只有模拟拒绝/成功合约测试，真实权限待验收。
- APK 账本只将已实测同名的 6 个 QQ RPC 标记 connected；其他已接通的 Web/Lite 业务保留契约差异，不扩大原 API 完成数量。
