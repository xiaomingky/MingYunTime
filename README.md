# 茗韵时光 · MingYun Time

**三平台音乐、双风格歌词、视频与赛事，一款 Windows 桌面播放器。**

[English](README_EN.md) · [下载 v3.6.1](https://github.com/xiaomingky/MingYunTime/releases/tag/v3.6.1) · [反馈问题](https://github.com/xiaomingky/MingYunTime/issues) · [GitHub Star](https://github.com/xiaomingky/MingYunTime)

基于 Vue 3 + Electron 22 构建，集成网易云音乐、QQ 音乐、酷狗概念版。除了发现、搜索、歌单和专辑，还提供可排序播放队列、本地音乐、经典 / Apple Music 风格歌词、桌面歌词、均衡器和统一下载中心。视频专区包含 B站、动漫、影视、网页解析与直播；娱乐专区提供 CS / VAL 赛事；智慧教材支持阅读、批注与配套音频。

> 本项目由 AI 辅助开发。英文 README 是文档翻译，不代表客户端具有英文界面。以下图片与 GIF 来自当前 v3.6.1 界面；在线推荐、榜单与赛事会随服务更新。歌词 GIF 演示界面动画，不含音频。本地音乐展示使用示例文件条目。

## 下载安装

1. 打开 [v3.6.1 Release](https://github.com/xiaomingky/MingYunTime/releases/tag/v3.6.1)，在 **Assets** 中选择 Windows 安装包 `.exe`；需要免安装方式时选择 `.7z`，完整解压后运行程序。
2. 安装包使用原生 **NSIS 向导**，可选择安装目录，并创建桌面 / 开始菜单快捷方式。
3. 启动后在左上角选择平台，再按需登录。普通使用无需安装 Node.js，音乐 API 服务与下载工具随客户端提供。
4. 首次启动本地 API 服务需要时间，数据暂未出现时稍等后刷新页面。

**系统：Windows 7 / 10 / 11，64 位。** 项目保留 Electron 22，并有 Windows 7 渲染兼容处理。旧电脑建议在 Apple Music 歌词中启用性能模式、30 FPS，关闭不需要的频谱和封面运动。系统媒体浮层、HEVC 解码等功能仍取决于 Windows 版本、驱动与编解码器。

在线播放、下载、高音质和账号操作依赖对应平台的授权、会员、地区与资源可用性。

## 三平台首页与登录

### 网易云音乐

![网易云首页](showimage/v3.6.1/netease-home.png)

- 左上角选择「网易云音乐」，进入「发现音乐」，顶部切换个性推荐、歌单、排行榜、歌手和最新音乐。
- 点击歌单封面进入详情；最新音乐中的歌曲可直接播放或使用更多菜单。
- 右上角「未登录」打开二维码、手机号、网易邮箱或 Cookie 登录。扫码后在手机确认，过期时刷新二维码。
- 登录后查看「我喜欢的音乐」、个人歌单和官方云盘，使用红心与可用的管理功能。
- 当前「每日歌曲推荐」卡片尚未接入完整播放入口；可从歌单、搜索或最新音乐开始听歌。

### QQ 音乐

![QQ 音乐首页](showimage/v3.6.1/qq-home.png)

- 左上角选择「QQ 音乐」，浏览推荐歌单、排行榜、新碟等可用内容；侧边栏提供歌手、歌单分类和喜欢的音乐。
- 点击歌单 / 专辑 / 歌手进入列表，再播放歌曲或安排队列。
- 登录框使用 QQ 音乐官网登录窗口，按提示用 QQ APP 扫码；也支持粘贴包含 `qm_keyst` 的 Cookie。
- 建议先登录再播放；播放链接依赖登录态，VIP / 版权资源需要相应权限。
- QQ 的歌单编辑功能与网易云 / 酷狗不同，三个平台不是完全一致的账号管理系统。

### 酷狗概念版

![酷狗概念版首页](showimage/v3.6.1/kugou-home.png)

- 左上角选择「酷狗概念版」，浏览轮播、新歌、新碟、推荐歌单；侧边栏进入歌手和歌单分类。
- 右上角登录支持概念版 APP 扫码、手机验证码、用户名及 Token / Cookie；需要验证时优先扫码或手机登录。
- 登录后可查看创建 / 收藏歌单，按页面入口新建、展开 / 收起和批量管理。
- 「设置 → 账号信息」显示业务 VIP 到期时间和领取记录，并提供一天 VIP、3 小时 VIP、升级畅听入口。是否成功以平台对当前账号的返回结果为准。

**切换平台会刷新界面。** 登录态、搜索历史与音质选项分别保存。切换后按目标平台重新选择歌曲即可；各平台播放权限独立。

## 搜索、歌单与专辑

### 搜索

在顶部输入歌名、歌手、专辑或歌单，按回车。搜索使用当前平台；通过结果标签切换可用类型。输入时可选搜索建议，历史按平台分别记录。

### 歌手、排行榜、分类与喜欢的音乐

- **歌手**：从发现页歌手标签或 QQ / 酷狗侧边栏进入；按页面提供的地区、性别、流派等筛选。点头像进入歌手详情，听热门歌曲、打开专辑；QQ 还提供可用的 MV 与相似歌手入口，酷狗歌曲列表可加载更多。
- **排行榜**：在发现页选排行榜，再点榜单查看歌曲。单首使用歌曲行操作，整榜使用详情页的播放 / 入队按钮。
- **歌单分类**：在首页歌单标签或 QQ / 酷狗分类页选择标签，浏览封面，按页面入口翻页或加载更多，再进入详情。
- **喜欢的音乐**：先登录当前平台，侧边栏打开喜欢的音乐，点击歌曲播放或使用更多菜单安排顺序；底部红心管理当前歌曲收藏。它与赛事 Star 无关。

### 歌单与专辑

![歌单详情](showimage/v3.6.1/playlist.png)

| 按钮 | 行为 | 适用场景 |
| --- | --- | --- |
| 播放全部 | 建立当前列表的播放队列并开始播放 | 完整听一张歌单 / 专辑 |
| 加入队列 | 追加整个列表到队列末尾 | 当前歌曲继续播，之后再听 |
| 下一首播放 | 把列表安排在当前歌曲之后 | 下一首开始听该列表 |
| 收藏 / 取消收藏 | 操作平台歌单收藏，通常需登录 | 留待以后听 |
| 分享 | 使用页面支持的分享入口 | 分享平台内容 |

自己的歌单可使用对应的编辑、删除、歌曲移除与封面修改入口。网易云与酷狗歌曲详情有「收藏到歌单」选择器，QQ 当前详情页不提供同样入口。评论、收藏者等标签依页面与接口支持展示。

### 歌曲行的 `…`

- **立即播放**：从所选歌曲开始，使用所在列表作为播放上下文。
- **下一首播放**：插到当前歌曲之后，不打断当前播放。
- **加入播放队列**：追加到末尾，不打断当前播放。

点菜单外或按 `Esc` 关闭。红心、下载、元数据编辑等另在各页面提供的按钮中，更多菜单专门负责这三种播放安排。

## 底部播放器与播放队列

### 播放器控制

| 位置 / 图标 | 怎么用 |
| --- | --- |
| 左侧封面与歌曲名 | 打开 / 收起歌曲详情，悬停查看完整标题 |
| 红心 | 收藏 / 取消收藏当前歌曲；在线操作通常需登录 |
| 循环 / 单曲 / 随机图标 | 点击切换模式，悬停查看名称 |
| 上一首、播放 / 暂停、下一首 | 控制当前队列 |
| 进度条 | 点击或拖动跳转 |
| 「词」 | 打开 / 收起歌词 |
| 电视图标 | 开启 / 关闭桌面歌词 |
| 音量条 | 拖动或滚轮调整 |
| 闪电图标 | 每次增加 50% 增益，最高 500%；过高可能失真 |
| 均衡器图标 | 打开 10 段均衡器 |
| `1x` | 选择 0.5 / 0.75 / 1 / 1.25 / 1.5 / 2 倍速 |
| 音质标签 | 选择当前平台音质，资源不足时可能回退 |
| 最右侧列表图标 | 打开 / 关闭队列抽屉 |

### 排列队列

1. 打开抽屉，按「播放记录 / 正在播放 / 接下来」确认当前位置。
2. 按住歌曲左侧点状**手柄**拖动，插入线指示放置位置。
3. 悬停歌曲行，点「下一首播放」快速安排；非当前歌曲可点 `×` 移除。
4. 「清空接下来」只移除后续项；垃圾桶清空整个队列，会提示确认并停止播放。
5. 点歌曲行立即播放该项，点抽屉外部或关闭按钮收起。

重复加入同一首歌后，各项仍可独立排序和移除。队列排序不会修改在线歌单原始顺序。队列、歌曲、索引与模式会保存；重启后不自动出声。

随机模式使用随机池，上一首沿真实播放历史回退；当前歌曲播放超过 3 秒时，「上一首」会先回到本曲开头。单曲循环下自然结束会重播，当前「下一首」按钮也会重播本曲；要切到别的歌曲，可点击队列中的目标项或选择歌曲行「立即播放」。

## 经典与 Apple Music 歌词

点底部封面或「词」打开详情，在歌词设置的「页面风格」选择经典 / Apple Music，选择会保存。

### 经典风格

![经典歌词动画](showimage/v3.6.1/classic-lyrics.gif)

- 左侧封面与歌曲操作，右侧同步歌词；点击歌词跳转到该句。
- 「沉浸 / 经典」改变经典页面内部背景，与页面风格切换不同。
- 有逐词数据时切逐词 / 逐行，没有则显示普通逐行。
- 设置可调字体、字号、歌词位置、封面样式等实际可用项。
- 点歌词来源，搜索网易云 / QQ / 酷狗候选，选对现场版、翻唱版或原版；不同候选不一定都有翻译与逐词。
- MV 按钮选择本地或线上匹配；红心、加到歌单、下载、分享、评论依平台展示。
- 英文歌词可进 AI 英文解析，选择 DeepSeek 或 MiMo v2.5，输入对应 Key 后开始。展开句子查看语法、时态、语态、词汇与变形；已缓存结果可再次读取。

### Apple Music 风格

![Apple Music 歌词动画](showimage/v3.6.1/apple-lyrics.gif)

封面与歌词分栏，支持跟随滚动、逐词高亮、弹性动画与远处歌词模糊。右上角齿轮设置：

| 设置 | 用法 |
| --- | --- |
| 页面风格 | 返回经典或保持 Apple Music |
| 封面样式 / 唱片旋转 | 专辑封面、CD、黑胶、唱片套，开关封面运动 |
| 歌词模式 | 有数据时逐词，否则逐行 |
| 性能模式 / 帧率 | 45 FPS 均衡或 30 FPS 节能 |
| 仅更新附近歌词 | 减少长歌词渲染负担 |
| 音频可视化 | 开关频谱，需要实际音频播放 |
| 歌词来源 / MV | 换歌词候选、本地或线上 MV |
| 翻译 / 翻译字号 | 有翻译数据时显示，12–30 px |
| 歌词间距 / 字号 | 间距 0–24 px，主字号 24–64 px |
| 字体 / 远处模糊 | 系统无衬线 / 宋体，开关非当前句模糊 |

手动滚动后可点「回到当前句」，也会稍后自动恢复跟随；点击句子跳转。风格设置不会生成资源缺少的歌词。

## 桌面歌词与音效

- 底部电视图标打开置顶桌面歌词，未锁定时可拖动。
- 锁图标启用鼠标穿透；保留的解锁按钮恢复拖动。关闭按钮收起窗口。
- 歌词相关设置支持字体、颜色、字号、透明度及复杂（封面与控制）/ 简约（歌词）模式。每次启动默认关闭桌面歌词。
- 均衡器有默认、流行、古典、摇滚、电子、人声、爵士、低音预设；10 段覆盖 32 Hz–16 kHz，范围 `-12 dB` 到 `+12 dB`。
- 首次打开 EQ 会启用，收起面板不会关闭音效，需使用面板开关。
- 系统媒体会话支持媒体键与可用系统控制；第三方任务栏媒体栏可读取标题、歌手、封面和播放状态，形式依 Windows 版本而异。

## 本地音乐、格式转换与歌词获取

![本地音乐](showimage/v3.6.1/local-music.png)

### 本地音乐

1. 点「添加 → 添加文件 / 添加文件夹」，等待扫描。
2. 点歌曲播放或「播放全部」，使用点状手柄调整本地列表顺序。
3. 复选框支持批量移除；移除列表项不等同于删除磁盘文件，以确认提示为准。
4. 铅笔编辑标题、歌手、专辑、年份、风格与封面等元数据；相机搜索封面；搜索按钮查找保存歌词；`…` 安排队列。
5. 「自动获取」按可用情况匹配封面 / 歌词，可保存图片与 `.lrc` 到歌曲目录；匹配有误时手动选其他版本。

常见 MP3、FLAC、WAV、OGG、M4A 可导入；实际解码取决于文件编码。

### 格式转换

顶部切「格式转换」，添加本地文件，检查识别信息，勾选后开始。支持列表含网易云 `ncm`、QQ `qmc` / `mflac` / `mgg`、酷狗 `kgm` / `kgma` / `vpr` 等。它尝试恢复原始格式，不通过重编码提升音质；新格式或缺少信息的文件可能不支持，查看单项结果与输出路径。

### 歌词获取

顶部切「歌词获取」，输入歌名与歌手，选择全部或单平台搜索。点击候选预览，选择解析版 / 原始文本、逐行 / 逐词、翻译与命名顺序，配置目录后保存 `.lrc`。候选存在不保证逐词与翻译都可用。

## 官方云盘与最近播放

- **官方云盘**仅网易云显示。登录后刷新歌曲；上传可多选文件，检查歌名、歌手、专辑、封面与歌词后确认，查看进度和匹配结果。
- **最近播放**用于找回历史歌曲，点击重播或使用更多菜单；历史不是在线歌单。
- 项目保留自建后端的云音乐 / 账号密码锁接口，需独立部署并配置，不是默认公共云服务。启用锁后访问受保护歌单需验证。

## 视频专区

侧边栏「视频」展开动漫、影视、B站；「本地视频」是文件、链接与网页解析入口。视频播放会协调音乐状态，避免两路声音同时播放。

### B站区

![B站视频专区](showimage/v3.6.1/video-bilibili.png)

1. 选择推荐、动画、音乐、游戏、知识等分类，或输入关键词搜索。
2. 使用类型选择器搜索视频、番剧、影视或直播等可用类型，选择排序并翻页。
3. 点击卡片进入详情，选择分 P / 剧集、画质、倍速、音量和弹幕，按需开启自动连播；同一视频有续播记忆。
4. 点作者 / 评论头像进入 UP 主页，浏览投稿、合集；简介可展开，评论回复可展开，图片可用灯箱缩放、拖动与下载原图。
5. 登录面板区分 Web 与 TV：Web Cookie 对应 Web 权限和收藏夹，TV Token 对应 TV 接口；二者不能互相替代，画质受账号与内容限制。
6. 登录后在「收藏夹」浏览收藏；点下载后到下载中心查看任务。

### 本地视频、链接与网址解析

![视频网址解析](showimage/v3.6.1/video-parser.png)

| 标签 | 使用步骤 |
| --- | --- |
| 本地视频 | 添加文件 / 文件夹，扫描元数据，点卡片播放，分页或批量移除 |
| 链接 / 直播流 | 添加名称与 URL，选自动 / MP4 / WebM / HLS / FLV / 直播，保存后播放、编辑、移除 |

## 统一下载中心

![下载中心](showimage/v3.6.1/downloads.png)

音乐、MV、动漫、影视、视频、教材统一进入侧边栏「下载」。

- 查看：全部 / 下载中 / 已完成 / 失败筛选，再选音乐、影视、动漫、MV、视频、文档分类。
- 管理：根据状态暂停、继续、取消、重试、移除；清除已完成清理记录，不等于删除文件。
- 详情：展开查看链接、路径、时间、进度、速度、错误；复制链接或打开文件夹。
- 自定义：粘贴 HTTP / HTTPS 直链，点识别获取文件名，按需改名，再开始下载。
- 齿轮：8 / 16 / 32 / 64 / 128 线程（默认 32），User-Agent、Referer、附加请求头；失败 / 限流时减线程，并发越高不保证越快。
- 目录：「设置 → 下载专区」选择统一目录或恢复系统默认。
- 记录存磁盘；恢复取决于状态与源。随客户端提供 aria2c、ffmpeg 等，支持相应分片与音视频合并。

## 常见问题

| 情况 | 处理 |
| --- | --- |
| 首页无内容 | 等服务启动刷新；网易云换线路；其他来源检查网络 |
| 不能播放 / 音质回退 | 登录，确认会员 / 地区 / 版权，尝试较低音质 |
| 歌词错版 / 无翻译 / 无逐词 | 换歌词源；没有的数据无法由风格生成 |
| Win7 / 旧机动画慢 | 性能模式、30 FPS、附近歌词，关频谱与封面运动 |
| 下载 403 / 429 | 减线程，检查登录、过期链接与请求头后重试 |
| B站画质受限 | 检查接口及对应 Web / TV 登录与会员 |
| 视频只有声音 | 检查实际编码；HEVC 依系统解码，可换编码版本 |
| 分区不见 | 设置恢复侧边栏分区 |
| 关窗后仍播放 | 检查是否托盘模式，用托盘退出或改直接退出 |

反馈请写版本、Windows 版本、平台、复现步骤和可公开截图，不附 Cookie、Token、API Key。

## 开发与构建

运行安装包无需开发环境。开发建议 Node.js 22 LTS 与 npm；基础前端需 Node.js 18+，当前某些依赖 / API 工具需要更新版本。Windows 安装包在 Windows 构建。

```bash
npm install
npm run dev
```

低内存用 `npm run dev:light`；完整构建：

```bash
npm run build
```

脚本准备三平台 API、运行 Vite 与 electron-builder，输出 `release/` 的 x64 NSIS / 7z。`npm run preview` 仅预览已构建前端；依赖 Electron IPC 的 QQ、赛事、下载等不是普通浏览器可完整运行的功能。

| 部分 | 技术 / 位置 |
| --- | --- |
| UI | Vue 3、Pinia、Vue Router、Lucide；src/views/、src/components/ |
| 播放 | HTML Audio / Web Audio；src/store/player.js |
| Apple 歌词 | Apple Music-like Lyrics 与适配；src/utils/apple-lyric-player.js |
| 桌面 / IPC | Electron 22；electron/ |
| 视频 | Artplayer、hls.js、mpegts.js / flv.js |
| 元数据 | music-metadata、node-id3 |
| 下载 / API | aria2c、ffmpeg、yt-dlp、三平台服务；resources/ |
| 构建 | Vite 5、vite-plugin-electron、electron-builder；build/、scripts/ |
| 展示 | showimage/v3.6.1/ |

Electron 通常启动网易云 3100、QQ 3200、酷狗 3300 服务。网易云 / 酷狗有在线回退，QQ 用 IPC。自建线路对照 `src/api/index.js`、`src/api/qq.js`、`src/api/kugou.js` 与主进程启动模块修改。

自建云音乐 / 账号锁使用 `VITE_CLOUD_BASE_URL`，后端与官网独立部署。AI Key 在界面配置、存本地，解析歌词发送到所选 AI 服务。
