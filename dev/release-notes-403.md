# 茗韵时光 v4.0.3

本次更新新增独立动漫源专区，并改进视频播放、搜索体验与播放稳定性。

## 新增与改进

- **独立动漫源专区**：在「视频」下新增「动漫源」，与原有动漫区分开；内置 17 个来源规则，提供发现、时间表、聚合 / 单来源搜索、丰富详情、选集、追番、历史和来源管理。
- **统一搜索体验**：动漫源与音乐搜索使用相同的搜索组件，支持搜索建议、独立历史记录、清除和回车提交；绿色焦点边框包含整个搜索框及来源选择器。
- **统一视频选集**：各视频分区使用选集抽屉，支持列表与多列切换、封面和标题；本地视频模式可浏览本地添加的播放列表。
- **播放器体验**：调整底部按钮和小窗布局，提供进度条悬停 / 拖动预览、画质增强、可选补帧、原画对比与状态显示，完善音量增强和流媒体缓冲恢复。
- **稳定性修复**：改进连续顺序播放恢复、视频加载超时与重试提示、网易云扫码及喜欢操作，以及汽水和 QQ 登录验证处理。
- **文档**：更新中英文 README，新增动漫源页面展示图。

## 下载

- `Setup.4.0.3.exe`：Windows 安装包。
- `MingYunTime-4.0.3-win.7z`：免安装版，完整解压后运行。
- `Setup.4.0.3.exe.blockmap`：安装包差分信息。
- `SHA256SUMS-v4.0.3.txt`：附件 SHA-256 校验值。

支持 Windows 10 / 11 x64。普通使用无需安装 Node.js，必要运行文件与下载工具随包提供；不需要另行部署旧音乐 API 服务。

## 验证与使用说明

已通过项目完整回归、动漫源规则样例检查、真实 GPU 视频增强与选集抽屉检查，并核对发布包内容和文件校验值。

在线来源可能受网站访问状态影响；登录、会员与内容权限由对应平台决定。流媒体增强用于缓冲与恢复，不会提高实际带宽。画质增强与补帧的性能取决于显卡、驱动和视频分辨率。
