04 / FEATURES

核心能力

从在线流媒体到本地高保真，从沉浸歌词到云端管理，每一个细节都为音乐爱好者精心打磨。

双平台在线音乐

网易云 + QQ 音乐双平台切换，海量曲库即点即播。私人 FM、每日推荐、歌单广场、排行榜、歌手专区一应俱全。

沉浸歌词

逐字高亮 YRC 动画、双语对照、桌面歌词悬浮、Apple Music 风格粒子效果。

本地管理

MP3 / WAV / FLAC / OGG / M4A / AAC / WMA / APE / OPUS 等 24 种格式全支持，ID3 标签智能识别，封面自动嵌入。

官方云盘与下载

网易云官方云盘上传管理、账号一键同步、密码锁保护、128 线程无损下载带速度显示、Web 后台独立管理。

MV 与影视

网易云 MV、动漫、影视统一采用 BiliPlayer 内核播放，支持 m3u8 流媒体、选集切换、倍速与清晰度调节。

音量增益

Web Audio API GainNode 节点驱动，音量最高增益至 500%，闪电按钮逐档调节，突破系统上限，小音量文件也能澎湃震撼。
